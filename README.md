# EDA-Case-study
Dataset containing historical commodity prices used for Exploratory Data Analysis (EDA), trend visualization, and outlier detection to derive market insights.

**Project Overview**

This project focuses on analyzing historical commodity price data to identify patterns, visualize distributions, and detect outliers using Python. The dataset (commodity_prices.csv) contains information about various commodities, their prices, and corresponding dates.

**Objective**

Perform Exploratory Data Analysis (EDA) on commodity price data.

Visualize the distribution of prices across all columns using box plots.

Detect and remove outliers to clean the dataset for accurate insights.

**Approach**

Imported and cleaned the dataset for analysis.

Used a for loop to iterate through all numerical columns and generated box plots using Matplotlib and Seaborn.

Identified outliers using the IQR (Interquartile Range) method.

Removed outliers to obtain a refined dataset for further statistical analysis and modeling.

**TOOLS & LIBRARIES USED**                                                     

Python — Data manipulation and analysis.

Matplotlib — Visualization of box plots for each column.

Seaborn — Enhanced visualization for better insights.

Pandas — Data handling and cleaning operations.

**OUTCOME**

The analysis provided a clear understanding of price variations among commodities, helped in detecting extreme values, and prepared a clean dataset for further analysis and forecasting.
